# Changelog

All notable user-facing changes, newest first. Categories:

**Added** (new features),
**Fixed** (bug and behaviour fixes),
**Removed** (things taken out),
**Info** (notes worth knowing).

## 2026-04-06

### Added
- **Alias Cycling Generator**: a new page for building keybinds that cycle through
  several actions.

### Fixed
- **Multimap downloads**: downloaded files are now named after your layout, and the
  on-page note shows the right file name.

## 2026-03-24

### Added
- **Multimap Generator**: a new page for building keybind layouts with several maps.
- **Previous key**: layouts can now have separate keys for going to the next and the
  previous map.
- **Reordering**: keys can be moved up and down in the list.

### Info
- **Chat Keybind Generator**: the alias keybind page is now called Chat Keybind
  Generator.

## 2025-11-23

### Added
- **One-line output**: the keybind page now also gives a one-line version you can paste
  into the console.

## 2025-11-22

### Added
- **First release**: a page that generates CS2 alias keybinds.
